# 🎂 ¡Feliz Cumpleaños Zopas! 🎮

Web interactiva personalizada inspirada en **Zenless Zone Zero (ZZZ)** y **Random Play**, creada para celebrar el cumpleaños de **Zopas** (Brochacho) antes de su cambio de servidor rumbo a España.

---

## ✨ Características

- 🎬 **Hero Inmersivo**: Fondo animado de Belle Summer en video continuo y estética CRT.
- 💌 **Mensaje de Cumpleaños**: Saludo personalizado de Belle de Random Play con reproductor de video vertical.
- 💿 **Random Play Vault (3D Disc Cascade Carousel)**: Carrusel 3D interactivo con los tres juegos candidatos de Steam:
  - *Megabonk*
  - *Dungeon Rampage Remastered*
  - *Mouthwashing*
- 🎰 **Banner Gacha S-Rank**: Modal interactivo de sintonización que reproduce la cinemática oficial de pull de ZZZ y revela el juego ganado con lluvia de confeti dorado.
- 🎵 **Random Play Audio Player**: Reproductor flotante con lista de canciones:
  - *Burning Desires* (ZZZ)
  - *Tu Cumpleaños* (Diomedes Díaz)
  - Pausa inteligente durante las tiradas de gacha y reanudación automática.
- ⚡ **Diseño New Eridu**: Tipografía HUD, tiras de advertencia hazard-tape, microinteracciones y efectos de sonido.

---

## 🛠️ Tecnologías

- **React 18** + **TypeScript** + **Vite**
- **Tailwind CSS**
- **Framer Motion**
- **Lucide React**
- **Canvas-Confetti**

---

## 🚀 Instalación y Ejecución Local

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev

# 3. Compilar para producción
npm run build
```
